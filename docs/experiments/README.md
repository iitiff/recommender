# Experiments

One short write-up per model experiment, so every change is measured and the
reasoning survives. Copy [TEMPLATE.md](TEMPLATE.md) to
`YYYY-MM-DD-short-name.md`.

**Where write-ups go:**
- **Here (public):** experiments on the fictional demo catalog or public
  datasets.
- **Private site repo:** anything using real user data, real catalog curation,
  or revealing tuned settings.

**Ground rules:**
- State the hypothesis and the decision metric *before* running.
- Always compare against Random and MostPopular.
- Report confidence intervals; with small data, say when a difference is noise.
- Negative results are results. Write them up too.
